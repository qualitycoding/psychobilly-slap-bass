# Decisions and decision rules

- **D-001 — Licensing:** license project source and combined binaries under AGPL-3.0-only, not the initially proposed GPL-3.0, because JUCE 9 offers AGPLv3 or a commercial licence. Verify the 9.0.5 licence text before freeze.
- **D-002 — Framework pin:** use JUCE 9.0.5 at `d60b7a78030661574a615b586d9325ba7a7fa7dd`, as requested if JUCE 9 exists.
- **D-003 — Mutation testing:** opt out for 0.1.0 because the suite combines realtime DSP, host validation and listening gates; a mature, low-cost mutation configuration has not been measured. Reconsider after the first implementation suite has a measured runtime.
- **D-004 — DSP architecture candidate:** evaluate an extended digital-waveguide string with fractional delay and frequency-dependent damping, a nonlinear string–fingerboard collision/contact path, and a separate body/radiation path. The pitched/body and contact components must remain separately controllable through the shipped mix. This is a candidate pending R6 stability, control and performance spikes, not a realism claim.
- **D-005 — Host validator:** pin pluginval v1.0.4 at `ed19c2c16b57a6d94db391bea3ef4a80b769d5bf`; run strictness 7, a fixed random seed, explicit sample rates and block sizes, and an additional repeated/randomised stress invocation from the first binary-producing step. Any disabled test requires a recorded waiver and cannot be used to conceal a failure.
- **D-006 — CI runner labels:** use `windows-2025` for Windows x64, `macos-15` for Apple Silicon and `ubuntu-24.04` for Linux x64. Do not use moving `-latest` labels.
- **D-070 — Pluck/body reference set:** use the seven pinned CC0 VSCO 2 CE pizzicato candidates recorded in `research/reference-candidates/manifest.json` for ordinary pluck/body blind comparisons and reference-spread analysis. Re-fetch by pinned URL and require the recorded SHA-256 before use.
- **D-071 — Slap validation fallback:** because no redistributable slap-specific reference has been verified, assess slap character through reproducible event-file demos and the fixed human listening questions, with no A/B-against-slap-reference claim. Ordinary pluck/body A/B coverage remains separate and cannot substitute for slap approval.
- **D-007 — Host-only editor contract:** expose the eight controls through host parameters and provide no bespoke editor in 0.1.0. `hasEditor()` returns `false` and `createEditor()` returns `nullptr`; headless validation uses `--skip-gui-tests` solely because no editor exists, not to bypass an implemented GUI failure.
- **D-008 — Realtime state boundary:** audio code reads cached `std::atomic<float>` parameter values. XML/APVTS `copyState()` and `replaceState()` are confined to host state callbacks off the audio thread; `processBlock()` must never call them.
- **D-009 — CI coverage waivers:** waive Linux ARM64 and alternate-libc Linux jobs for 0.1.0 because neither is an intake-supported binary target. The declared macOS ARM64, Windows x64 and Linux x64 targets each retain a native versioned-runner job. A later platform addition requires a new decision and matching CI job before support is claimed.
- **D-010 — Package-index fallback:** when the configured Python mirror fails DNS or connection setup, retry the identical pins with `pip --index-url https://pypi.org/simple`; do not change package versions or treat mirror failure as package absence.
- **D-011 — pluginval race fallback:** keep stable v1.0.4 as the primary validator. If CI reproduces the `PluginInfoTest` message-thread race documented in issue #149, preserve the failing log, confirm the independent host/DSP tests still run, and use a source build at exact fix commit `fea38e7ed6a5e35b2e9122bb5685fc3dc8fe9a01`; never switch to a moving branch or suppress the test. Treat any other failure as a product failure until independently disproved.
- **D-012 — State and platform hardening:** cap host state input at 65,536 bytes before parsing; require exactly one shallow `PsychobillySlapBass` XML root with schema `1`, known parameter IDs, finite in-range values and no trailing payload; reject malformed or future-schema state without changing the active sound. Set macOS deployment target 12.0 explicitly rather than inheriting a host default.
- **D-013 — Licence artifacts:** ship the AGPL-3.0-only licence, JUCE licence notice and VST3 SDK MIT notice with source and any gated binary package; record the exact source commit corresponding to a binary. Public release remains prohibited before G-002.
- **D-014 — Validator coverage proof:** require pluginval exit zero, non-empty logs containing the expected product ID, strictness 7, fixed seed, every requested rate/block-size combination and `ALL TESTS PASSED`, with no `FAILED`, crash, timeout or unexpected `disabled` marker. Independent DSP, state, realtime and event tests remain mandatory; pluginval alone is never sufficient.
- **D-015 — Blind-test integrity:** each 12-pair round contains exactly six reference-on-A and six reference-on-B assignments in seeded shuffled order. The base64 key remains sealed until all answers are recorded; every disclosed round is followed by a newly seeded bundle. Record one-letter response bias but do not convert it into a realism pass. Evidence branches contain only WAV/JSON/Markdown evidence, checksums and attribution—never credentials, local paths, host state or listener-identifying metadata.
- **D-016 — Spike-informed architecture:** retain D-004 with the R6 global corrections: low-passed pluck excitation, bounded collision correction, brightness filtering on both contact noise and collision components, a second-order radiation filter with cutoff `350 + 350 * string_tension` Hz, fixed shipped-path mix scale `0.24`, and no renderer normalisation. These are the equations the implementation tests must reproduce; they remain a synthesis hypothesis, not a realism claim.
- **D-017 — Measured DSP gates:** require all finite output and no subnormals; extreme-corner peak at most `0.34`; matched-note absolute pitch error at most 21 cents; ordinary-pluck candidate/reference absolute log2 spectral-centroid difference at most `1.433155096971784`; all eight controls strictly increasing at `0, 0.25, 0.5, 0.75, 1`. Known-answer limits are 5 cents unconstrained pitch, 3 ms onset, 5% exponential T60 and 2 Hz sine centroid. Decay/reference spread is diagnostic only because R6 found a 2.983474685004709 log2 mismatch; no realism claim may use that diagnostic as a pass.
- **D-018 — Performance gate:** at 96 kHz, 64-sample blocks and eight fully active voices, require seven five-second runs with maximum RTF at most `0.25` separately on each versioned CI runner. The first passing run on each runner commits/records that runner's baseline; later runs allow at most 10% regression while still satisfying the absolute ceiling. A miss requires optimisation or G-005 human rescope, never silent relaxation. The local spike is not evidence for other runners.
- **D-019 — Voice/coupling bounds:** use eight slots with same-note retrigger in place, steal the quietest then oldest voice, and crossfade old/new material over 10 ms within the slot so fades do not create a ninth voice. Sympathetic input is `0.015 * (sum(other seven previous outputs))`, spectral radius `0.105`; all delay storage is preallocated at prepare time.

## Execution forks

- If a dependency or host is unreachable, retry the same authenticated operation at most three times with bounded backoff; if still unreachable, record the exact evidence and use the pre-decided CI path or halt when no equivalent exists.
- If a check fails, do not weaken or skip it; correct the implementation or write `TEST_CHALLENGE.md` when the frozen check itself is invalid.
- For an unanticipated situation, choose the most reversible option that does not expand scope and log it in `DEVIATIONS.md`; halt for changes to frozen tests, security, data integrity, public interfaces or research integrity.
